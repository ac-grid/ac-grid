## Sections for acgrid.dev

1. **Home**: Hero (tagline + CTA), Features grid, Quick Start code, link to Docs & Samples
2. **Docs**: Sidebar or tabs – Getting Started, API Reference, Features (Sorting, Filtering, Theming)
3. **Samples**: One subsection per feature – Basic Grid, Sorting, Filtering, Theming, Column Reorder, Row Reorder
4. No FAQ/contact unless added later; keep focus on docs + live samples.

---

## Anti-Patterns (reminder)

- No WSXJS-only or unrelated framework docs on the site
- No emoji icons; use SVG (Heroicons/Lucide)
- cursor-pointer on all clickable; transitions 150–300ms
